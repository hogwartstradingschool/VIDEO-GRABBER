VIDEO GRABBER (Android) - GitHub se APK
1) Is folder ka sab kuch (hidden .github folder samet) ek nayi GitHub repo mein push karo.
2) Repo > Actions > "Build APK" chalne do (5-8 min). Khatam hone par Artifacts > VideoGrabber-APK download karo.
3) APK phone mein install karo. App kholo: Overlay + Accessibility (+Notifications) allow karo, START dabao.
4) Android 13+: Accessibility greyed ho to Settings > Apps > Video Grabber > ⋮ > "Allow restricted settings", phir dobara allow karo.
Build fail ho to Actions ka error log mujhe paste kar do.
